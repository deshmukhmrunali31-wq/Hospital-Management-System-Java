# Hospital Management System

## Project Overview
The Hospital Management System is a Java-based application designed to manage hospital-related information efficiently using Java and MySQL.

## Technologies Used
- Java
- MySQL
  
## Project Modules
- Doctor Management
- Patient Management
- Hospital Management

## Project Structure
```text
Hospital-Management-System-Java/
│
└── src/
    ├── Main.java
    └── HospitalManagementSystem/
        ├── Doctor.java
        ├── Patient.java
        └── HospitalManagementSystem.java
```

## Objective
To develop a simple hospital management application that helps organize hospital information using Java programming.
